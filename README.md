# Vedant Enterprises — कर्मचारी हजेरी, ओव्हरटाईम व वेतन व्यवस्थापन वेबसाईट

---

## 🌟 नवीन वैशिष्ट्ये व अद्यतने (Key Highlights)

1. **शाखा-मुक्त एकत्रित व्यावसायिक वेबसाईट (Clean Unified Website — No Branches)**:
   - शाखेचा गोंधळ पूर्णपणे काढून टाकण्यात आला आहे.
   - सर्व कर्मचारी, हजेरी, ओव्हरटाईम व वेतन थेट **वेदांत एंटरप्रायझेस (Vedant Enterprises)** शी जोडलेले आहेत.
   - आधुनिक एंटरप्राइज SaaS डिझाईन: इंटर फॉन्ट, स्वच्छ स्लेट कार्ड्स, रिस्पॉन्सिव्ह नेव्हिगेशन बार.

2. **ओव्हरटाईम विभाग (Overtime Section — ताशी रु. ७४ दर)**:
   - **अधिकृत ओव्हरटाईम दर**: **रु. ७४ प्रति तास (₹74 / Extra Hour)**.
   - **दैनिक हजेरीमध्ये थेट नोंद**: दररोजच्या हजेरी पत्रकात प्रत्येक कर्मचाऱ्यासमोर थेट ओव्हरटाईम तास (उदा. +1h, +2h) नोंदवण्याची सोय व त्वरित देय रक्कम डिस्प्ले.
   - **स्वतंत्र ओव्हरटाईम लेजर**: वेतन चक्रानुसार कर्मचाऱ्यांचे एकूण तास, प्रति तास दर (₹७४) आणि एकूण ओव्हरटाईम देयक तपासण्याची व Excel डाऊनलोड करण्याची सोय.
   - **पगारामध्ये समाविष्ट**: `निव्वळ पगार = कमावलेला मूळ पगार + ओव्हरटाईम रक्कम (तास × रु. ७४) − ॲडव्हान्स कपात − PF − PT`.
   - **पगार स्लिपमध्ये तपशील**: पगार स्लिपवर ओव्हरटाईम तास आणि रकमेचा स्वतंत्र तपशील.

3. **२० तारखेपासून पुढील १९ तारखेपर्यंत वेतन चक्र (20th to 19th Salary Cycle)**:
   - वेतन व हजेरी महिना **२० तारखेपासून पुढील १९ तारखेपर्यंत** अचूकपणे चालतो (उदा. २० ऑक्टोबर ते १९ नोव्हेंबर).

4. **केंद्रीत मस्टर रोल Excel (.xls) व स्वच्छ PDF प्रिंट**:
   - **Centered Excel Export**: वर वेदांत एंटरप्रायझेसचे नाव, कालावधी व मस्टर शीर्षक मध्यभागी (Center) आणि खाली परिपूर्ण उपस्थिती व ओव्हरटाईम मस्टर रोल.
   - **Clean PDF View**: वरील डॅशबोर्ड कार्ड्स वगळून थेट **VEDANT ENTERPRISES** पासून खालील मस्टर शीट प्रिंट/पीडीएफ होते.

5. **कर्मचारी व्यवस्थापन व ॲडव्हान्स लेजर (Staff & Advance Management)**:
   - नवीन कर्मचारी जोडणे, पद/विभाग, बँक तपशील, मूळ पगार नोंद.
   - ॲडव्हान्स कर्ज नोंद व दरमहा मासिक पगारामधून आपोआप हप्ता (EMI) कपात.

6. **Firebase Cloud रिअल-टाईम सिंक (Cloud Storage & Sync)**:
   - **Firebase Firestore** (`vedant-enterprises-6544a`) द्वारे सर्व मोबाईल व संगणकांवर आपोआप रिअल-टाईम सिंक.
   - इंटरनेट नसतानाही ऑफलाइन काम करते व इंटरनेट सुरू होताच क्लाउडवर अपडेट होते.

7. **द्विभाषिक प्रणाली (मराठी व English)**:
   - टॉपबारवर एका क्लिकमध्ये **मराठी ⇄ English** भाषा बदलण्याची सोय.

## 🚀 सुरू कसे करावे? (How to Run)
1. **GitHub Pages द्वारे थेट ऑनलाईन**: 
   - Repository Settings -> **Pages** -> Source: **Deploy from a branch** -> Branch: **main** -> **/ (root)** -> Save.
   - Live URL: `https://vedantpotdar308-cyber.github.io/attendence-system-/`
2. **स्थानिक पातळीवर (Offline/Local)**:
   - `index.html` थेट ब्राऊझरमध्ये उघडा किंवा `Start_App.bat` चालवा.
3. **स्थानिक Node सर्व्हरसह (ऐच्छिक)**:
   - `Start_Server.bat` चालवा (पोर्ट ५००० वर सुरू होतो: `http://localhost:5000`).

# Vedant Enterprises — कर्मचारी हजेरी व वेतन व्यवस्थापन प्रणाली
### Professional Multi-Branch Attendance & Salary Management System (20th to 19th Cycle)

---

## 🌟 अद्ययावत वैशिष्ट्ये (Key Features)

1. **मल्टि-डिव्हाइस ऑटोमॅटिक रिअल-टाईम सिंक (Multi-Device Automatic Real-Time Sync)**:
   - कोणत्याही शाखेने मोबाईल किंवा कॉम्प्युटरवरून हजेरी नोंदवली, नवीन कर्मचारी जोडला किंवा ॲडव्हान्स दिला तर तो **दुसऱ्या डिव्हाइसवरील मुख्य ऍडमिनला एका सेकंदात आपोआप रिअल-टाईम सिंक होतो** (Server-Sent Events तंत्रज्ञान).
   - ऍडमिनला स्क्रीन रिफ्रेश करण्याचीही गरज नाही; आकडेवारी आणि मस्टर थेट डोळ्यांसमोर अपडेट होते.
   - इंटरनेट किंवा स्थानिक नेटवर्क नसतानाही ऍप चालू राहते आणि नेटवर्क येताच आपोआप सिंक होते.
   - टॉपबारवर लाइव्ह सिंक बॅज (🟢 ऑनलाईन सिंक) उपलब्ध आहे.

2. **शाखा लॉगिन पानावरून मुख्य ऍडमिनचा पर्याय पूर्णपणे हटवला (Clean Branch Login)**:
   - शाखा ऍपच्या (`index.html`) लॉगिन पानावरून मुख्य ऍडमिन लॉगिनचा पर्याय किंवा लिंक **पूर्णपणे काढून टाकण्यात आला आहे**.
   - शाखा कर्मचाऱ्यांना केवळ त्यांची शाखा निवडणे आणि पासवर्ड टाकणे एवढाच पर्याय दिसेल. मुख्य ऍडमिनचे स्वतंत्र ऍप (`admin.html`) फक्त मुख्यालयाकडे सुरक्षित राहील.

3. **स्मार्टफोन व मोबाईलसाठी परिपूर्ण ऑप्टिमायझेशन (Mobile Phone Optimized UI)**:
   - **मोबाईल बॉटम नेव्हिगेशन बार (Bottom Nav Bar)**: मोबाईल ऍपप्रमाणे खाली ठळक ५ बटणे (📋 हजेरी, 📅 मस्टर, 👥 कर्मचारी, 📊 वेतन, ☰ मेनू).
   - **टच-फ्रेंडली हजेरी कार्ड्स (Touch Attendance Cards)**: मोबाईलच्या स्क्रीनवर गोंधळ न होता प्रत्येक कर्मचाऱ्यासाठी मोठे, स्पष्ट `[ P ] [ A ] [ H ] [ CL ] [ WO ] [ HL ]` चे टच बटन्स.
   - **स्मार्ट मस्टर रोल (Sticky Muster Table)**: मोबाईलवर मस्टर रोलमध्ये १ ते ३१ तारखा पाहताना डावीकडील कर्मचाऱ्याचे नाव स्क्रीनवर खिळवून (Sticky) राहते, ज्यामुळे मस्टर तपासणे अत्यंत सोपे होते.
   - **स्मूथ मोबाईल ड्रॉवर (Drawer Menu)**: डावीकडून सहज उघडणारा आणि बंद होणारा मेनू.

4. **स्वतंत्र मुख्य ऍडमिन पोर्टल (Dedicated Central Admin Portal - `admin.html`)**:
   - मुख्य ऍडमिनसाठी स्वतंत्र पोर्टल उपलब्ध केले आहे.
   - **सर्व माहिती एकाच ठिकाणी**: सर्व ५ शाखांची उपस्थिती, हजेरी, वेतन, ॲडव्हान्स आणि वैयक्तिक कर्मचाऱ्यांचे सविस्तर मस्टर रोल अहवाल.
   - **तारीख बदल मंजुरी**: शाखांनी पाठवलेल्या हजेरी तारीख बदल विनंत्या मुख्य ऍडमिन एका क्लिकवर मंजूर किंवा नाकारू शकतात.
   - **एकत्रित वेतन अहवाल (Consolidated Payroll)**: सर्व शाखांचा एकत्रित वेतन अहवाल व Excel/PDF एक्सपोर्ट.

5. **ऍप इन्स्टॉलेशन सुविधा (Fully Installable Application)**:
   - **Windows डेस्कटॉप शॉर्टकट्स**: `Install_Desktop_App.bat` वर डबल क्लिक करताच तुमच्या Windows डेस्कटॉपवर दोन ऍप्सचे अधिकृत आयकॉन तयार होतात:
     - 🏢 **Vedant Branch App** (शाखांसाठी)
     - 🛡️ **Vedant Central Admin** (मुख्यालयासाठी)
   - **PWA इन्स्टॉल (Chrome / Edge / Android Phone)**:
     - ऍपमधील **"📲 ऍप इन्स्टॉल करा (Install App)"** बटणावर क्लिक करून थेट संगणकावर किंवा मोबाईलवर स्वतंत्र ऍप म्हणून इन्स्टॉल करता येते.

6. **२० तारखेपासून पुढील १९ तारखेपर्यंत वेतन चक्र (20th to 19th Salary Cycle)**:
   - वेतन व हजेरी महिना **२० तारखेपासून पुढील १९ तारखेपर्यंत** अचूकपणे चालतो (उदा. २० ऑगस्ट ते १९ सप्टेंबर, २० सप्टेंबर ते १९ ऑक्टोबर).
   - महिन्यातील प्रत्येक दिवस अचूकपणे एकाच चक्रात येतो, कोणत्याही दिवसांचे ओव्हरलॅप होत नाही.

7. **मस्टर रोल Excel आणि उपस्थिती पत्रक PDF (Clean Exports)**:
   - **Excel Export**: केवळ हजेरी मस्टर रोल (कर्मचारी नाव व १ ते ३१ तारखांचे हजेरी कोड P/A/H/CL/WO/HL).
   - **PDF Export**: स्वच्छ उपस्थिती पत्रक (Presentee Sheet - केवळ नाव, उपस्थित दिवस, रजा व सुट्ट्या). यात अनावश्यक स्क्रीनशॉट्स किंवा बटणे येत नाहीत.

8. **हजेरी तारीख बदलासाठी ऍडमिन मंजुरी (Date Change Approval Gate)**:
   - आजची तारीख सोडून मागील तारखेची हजेरी नोंदवण्यासाठी ऍडमिन पासवर्ड किंवा मुख्य ऍडमिनकडे मंजुरी विनंती पाठवणे बंधनकारक आहे.

9. **मराठी व इंग्रजी भाषा स्विचिंग बटण (Bilingual Toggle)**:
   - **लॉगिन पानावर** व **अ‍ॅपच्या मुख्य टॉपबारवर** ठळक मराठी ⇄ English बटण उपलब्ध आहे.

10. **लॉगिन पानावरून पासवर्ड हिंट्स हटवले (Password Hints Removed)**:
    - लॉगिन स्क्रीनवरून सर्व पासवर्ड हिंट्स पूर्णपणे काढून टाकण्यात आले आहेत. स्क्रीन सुरक्षित आणि व्यावसायिक दिसते.

11. **लॉगिन लक्षात ठेवा (Remember Me)**:
    - लॉगिन करताना **"लॉगिन लक्षात ठेवा (Remember Me)"** चेकबॉक्स उपलब्ध आहे. ब्राउझर बंद करून पुन्हा उघडल्यावर थेट ऍप उघडते.

12. **नमुना कर्मचारी व Firebase पूर्णपणे काढून टाकले (Pure Clean Offline Storage)**:
    - सर्व सॅम्पल/डमी कर्मचारी काढून टाकण्यात आले आहेत (नवीन सुरुवातीसाठी डेटा रिकामा आहे).
    - सर्व Firebase स्क्रिप्ट्स व कोड काढून टाकण्यात आले आहेत.

13. **एका कर्मचाऱ्याची दोन शाखांमध्ये नोंदणीस प्रतिबंध (Cross-Branch Duplicate Prevention)**:
    - नवीन कर्मचारी जोडताना संपूर्ण शाखांमध्ये नाव, मोबाईल क्रमांक किंवा बँक खात्याची तपासणी केली जाते.

14. **"धाराशिव" शाखेचे नाव बदलून "उमरगा" (Branch Renamed to Umarga)**:
    - शाखा ३ चे नाव व जिल्हा **"शाखा ३ (उमरगा)" / "उमरगा (Umarga)"** असे करण्यात आले आहे.

## 🚀 ऍप कसे चालवावे व मल्टि-डिव्हाइस सिंक कसे वापरावे?

### पायरी १: एका कॉम्प्युटरवर सर्व्हर सुरू करा (Start Sync Server)
- फोल्डरमधील **`Start_Server.bat`** वर **डबल-क्लिक करा**.
- काळ्या विंडोमध्ये खालीलप्रमाणे पत्ते दिसतील:
  - `Local Access: http://localhost:5000` (या कॉम्प्युटरसाठी)
  - `Mobile / Network: http://192.168.x.x:5000` (मोबाईल व इतर डिव्हाइसेससाठी)

### पायरी २: कॉम्प्युटरवरून चालवणे
- **शाखा ऍप**: **`Start_Branch_App.bat`** किंवा डेस्कटॉपवरील **Vedant Branch App** वर क्लिक करा.
- **मुख्य ऍडमिन**: **`Start_Admin_App.bat`** किंवा डेस्कटॉपवरील **Vedant Central Admin** वर क्लिक करा (पासवर्ड: `admin123`).

### पायरी ३: मोबाईल फोनवर चालवणे व इन्स्टॉल करणे
- मोबाईल त्याच वाय-फाय नेटवर्कवर कनेक्ट करा.
- मोबाईलच्या Chrome / Safari ब्राउझरमध्ये **`http://192.168.x.x:5000`** (शाखा ऍपसाठी) किंवा **`http://192.168.x.x:5000/admin.html`** (मुख्य ऍडमिनसाठी) उघडा.
- खाली **"📲 ऍप इन्स्टॉल करा (Install App)"** बटणावर क्लिक करून मोबाईलच्या होम स्क्रीनवर ऍप इन्स्टॉल करा.
- शाखेतून मोबाईलवर केलेली कोणतीही हजेरी नोंद **मुख्य ऍडमिनच्या मोबाईलवर किंवा कॉम्प्युटरवर तत्काळ रिअल-टाईम सिंक होईल!**
